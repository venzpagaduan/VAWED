# Wedding Invitation

A modern, responsive wedding invitation page for Venz and Angeline.

## Preview locally

Open [index.html](index.html) in a browser, or serve the folder with a simple local server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy to GitHub Pages

1. Push this folder to a GitHub repository.
2. In GitHub, enable Pages and select the GitHub Actions deployment source.
3. The included workflow in [.github/workflows/deploy.yml](.github/workflows/deploy.yml) will publish the site automatically on pushes to the main branch.
